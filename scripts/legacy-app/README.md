# 舊 App 測試遷移紀錄

原始來源由 `generated/source-manifest.json` 指定，原 App 來源維持唯讀。
`build-reference.mjs` 只將本輪獲授權的危老面積檢核修正加入隔離測試用編譯；未改寫原 App 檔案。
執行 `npm run verify:legacy-app`，輸出保存在 `qa/legacy-app`；原本會寫入 App 文件夾的測試成果改存隔離工作目錄。

本輪六支測試的調整：

| 測試 | 調整測試資料或接入方式 | 保留驗證 |
| --- | --- | --- |
| bonus-assessment | 明列50%／30%測試上限、危老原合格基地與鄰地0㎡、危險建物適用比例100% | 原有細項加總、優先順序、地方20%／合計50%、容移倍數與外部1/3、到期日及案件往返 |
| basement-demand | 明列原規劃值、屋突條件、原案核准文件對照日期；保留地下需求模式 | 原2805.45㎡、16車位、地下2層等既有獨立數值及限制檢核 |
| legal-parking | 先建立工作區，再明列本算例規劃值；使用完整 App 匯出以驗證工作區保存 | 原幾何公式、無障礙數量、轉彎與坡道面積、地方停車規則及案件還原 |
| small-site-parking | 明列規劃值並保留現行屋突檢核；評估資料仍為合成算例 | 原停車法定需求、實際容量、逐層空間、地面無障礙、指定數量及不符條件攔截 |
| tdr-application | 明列上限與固定B4的80%開挖規劃條件，供容移串接驗證 | 原兩地容移資格、比例、上限、取得方式及固定B4斷言 |
| quantity-reserve | 明列規劃值與地下預留25%；空白必填資料改驗證缺件 | 原逐層加總、面積分類、登記分攤、免計容積上限與固定B4斷言 |

另納入原先已通過的工業、混合分區、法規核心、既有許可容移、屋突與面積分配六支檢核，共12支。
測試中使用的歷史規劃值只存在於算例；網站的留白輸入及其他計算規則維持原狀。
