## 新增禁則

禁用「帳算清楚」「算清楚」「算得清楚」，以及以「帳」泛指成本、分配、利益或責任的套語。不能刪除禁詞後改用另一個抽象結論。依句意列明工程款、費用項目、分回房地、補繳差額、付款人、收款人或履行責任。

## 後續盤查

每次改稿與上架前執行 `npm run verify:article-copy` 阻擋禁用表述，並以 `npm run audit:article-wording` 列出注意詞彙的文章網址、欄位及完整句子。注意項目逐句記錄改寫內容或保留理由，不能以命中次數判定文章品質。
