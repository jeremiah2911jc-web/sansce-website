# 工業土地與廠房開發：核定開發範圍與執行紀錄

確認日期：2026-10-24。使用者要求按本規劃執行，網站與 App 同步，本機預覽，不發布。

## 固定範圍

新增與集合住宅並列的「工業土地與廠房開發」入口，共用土地、證據、分區、文件覆核與報告核心，不以住宅比例改名替代。

流程：土地身分 → 預定用途 → 開發途徑 → 基準及原容積 → 獎勵與容移 → 逐棟逐層用途及配置 → 成果。

土地身分分開都市計畫工業區、非都市土地分區與編定；園區及核定計畫另加限制。先完整核對臺北、新北都市計畫工業區，其他制度保留獨立身分，不能冒用兩市一般規定。

開發途徑包含一般新改建、都市更新、工業區立體化及變更／許可。都市更新、立體化、容移之併用、母數、個別及合計上限須依官方條文與附件判斷，不以政策宣傳數字預填。未取得可直接適用規則時停止相關合計，不自動視為禁止或允許。

用途分列生產、倉儲、研發、辦公、展售及附屬設施；工業使用總量與建築計容總量分開。道路、公設、廢巷另列採計依據。原容積、獎勵、容移不能重複計入。

規劃試算與依文件覆核分流；空白不等於零，不自動帶獎勵比例。上游修改後舊結果失效。案件保存、版本、匯入與報告須包含工業資料。

網站只到前期數量、條件與報告；成本、期程、出售／出租／自用財務留在 App。不能直接把工業計容面積視為可售／可出租面積。
