- 互動：空白阻擋、缺漏定位、假設基地計算、修改後失效、取消清除、工具往返保留、人工清冊及方案建立均實際操作。見interaction-checks.json。
- 尺寸：1280／1024／800桌面；360／390／430手機介紹均無水平溢出，手機無輸入欄位及方向區。桌面控制外框52px，具名助理位於內容外側。
