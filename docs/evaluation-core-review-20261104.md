# 土地開發評估計算盤查（2026-11-04）

本次發布範圍為規劃預設值編排、分棟配置、反計容積說明及其回歸測試。其餘服務頁、文章、追蹤及受保護報告內容未修改。

## 本輪計算修正

- 分棟地上停車面積尚未具備法定車位數及免計適用資料時，全數先計入容積，房屋可售面積仍扣除該停車空間；避免從樓板直接扣除而產生額外免計面積。
- 地下車道缺少停車服務用途時，先歸入計容空間；地下用途加總失衡時停止輸出數量。用途完整後重新檢討免計。
- 獎勵計算回傳錯誤時停止輸出分棟數量，沿用原獎勵路徑與上限檢查。
- 每一地下層分別檢查基地適用的開挖上限，超限配置列於結果及報告待調整事項。
- 純空白字元依缺值處理。

原單棟共用核心函式內容維持一致，分棟呼叫共用的逐層、地下室、屋突及獎勵檢核。全案機電免計上限採計一次，各棟及共用地下室各自加總。參考文件數值只供差異比較，未進入計算輸入。

## 法規核對範圍

- [建築技術規則建築設計施工編第162條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0070115&flno=162)：逐層梯廳、陽台及全案機電等免計條件。
- [第60條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0070115&flno=60)：停車尺寸、坡道與平面停車免計面積上限。
- [第1條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0070115&flno=1)：建築投影、屋突高度及投影比例。
- [第141條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0070115&flno=141)、[第142條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0070115&flno=142)：防空避難面積及固定設備條件。

本輪核對面積計算與上述條件。實際地號適用都市計畫、限高、救災、停車排位、結構、登記資格及共有分配，仍依個案文件及圖說確認。分棟配置的地上停車及未定用途空間採保守計容，未授予尚缺依據的免計資格。
