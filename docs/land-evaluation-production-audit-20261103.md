## 結論

**發現兩項會影響允建容積的上限問題，均已在正式站及現行核心重現；本版尚未達到「計算核心已全部核對正確」的驗收條件。**

- 個案容移上限20%可能被一般30%覆蓋，25%目標仍被全數採用。1,600㎡、基準容積300%的範例，多列允建容積240㎡。
- 一般危老快速估算仍採固定40%限制。1,600㎡全為合格基地、2026-11-03申請、無合法原容積替代依據時，一般基本獎勵上限30%加規模9%，最多39%；輸入40%仍產生結果，多列48㎡。
- 新北依法劃定更新地區的容移評點1.3倍已在核心；須勾選適用條件。快速填入容移目標25%時，25%直接作為申請目標，不再自動乘1.3。
- 另有報告版本日期、未採用設備文字及未採用模式的零值摘要殘留。現有測試通過範圍與未通過項目分列於後。

兩項上限問題均可追溯至既有共用核心；本次查核沒有將它們歸因於最後一批介面更新。

## 已重現的計算問題與驗收條件

### P1：個案較低容移上限遭覆蓋

觸發：新北市，基地1,600㎡、建蔽50%、容積300%、都更50%、容移目標25%；選用個案文件上限20%，保留容移取得資料。正式站開啟取得方式後選代金，再改回取得方式未定，也可觸發。

核心位置：src/land-evaluation/generated/core.mjs 第4025行。當 tdrApplication 存在或使用細項評定，tdrLimit 直接改採 assessment.tdrCap，未與個案較低限制取較小值。

| 同組條件 | 現行結果 | 保留20%限制應得 |
| --- | --- | --- |
| 容移採計 | 25% | 20% |
| 允建容積 | 8,400㎡ | 8,160㎡ |
| 核心固定比較範例房屋可售 | 3,810.27坪 | 3,710.38坪 |
| 該比較範例戶數 | 113戶 | 110戶 |

允建容積多240㎡；可售差99.89坪為同一組停車及配置假設下的結果。正式操作使用通則停車，得到可售3,738.93坪、59車位；兩組範例的停車設定不同，分開留存，均採容移25%及允建8,400㎡。

法源：[中央容移辦法第4、8條](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0070028)、[新北容移要點第13點](https://web.law.ntpc.gov.tw/Scripts/FLAWDAT0202.aspx?fcode=C0150015)。個案都市計畫與較嚴限制須保留。

修正驗收：有無取得資料、快速／細項、新北／臺北、匯入舊案均測；地方一般上限、個案上限、評點、實際可取得量分別取限制值；畫面上限、核心採計、摘要及報告一致。不得因開啟取得方式就提高個案上限。

### P1：危老快速40%未依本次面積與時程限縮

觸發：一般新申請、全案1,600㎡均合格、2026-11-03、無原容積替代依據；快速填危老40%、容移0%。

核心位置：src/land-evaluation/generated/core.mjs 第3988行，快速模式採 Math.min(40, rates.danger)。現行細項模式已有面積及時程計算，快速模式未共用該結果。

| 計算段落 | 本案一般條件 |
| --- | --- |
| 基準容積 | 1,600×300%＝4,800㎡ |
| 一般基本獎勵上限 | 30% |
| 本次規模獎勵上限 | 2%＋14×0.5%＝9% |
| 本次時程獎勵 | 0% |
| 一般最大獎勵 | 39%：允建6,672㎡ |
| 現行快速40%結果 | 允建6,720㎡，多48㎡ |

同組固定核心比較，可售由3,019.25坪增為3,038.73坪；正式通則停車操作得可售2,968.24坪。可售結果依停車與配置條件變動；48㎡允建差額固定。

法源：[危老條例第6條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0070249&flno=6)、[危老容積獎勵辦法](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0070258)。合法原容積較高的替代基準須另外核對，本項結論限一般基準容積案。

修正驗收：快速與細項採同一面積、資格、申請日及上限來源；合格基地／鄰地留白不可當0；原容積替代另列依據。補測200、1,600、1,800㎡，各時程交界與2027-05-31前後；既有核准案件另測，保留核准文件適用。

## 新北容移1.3倍：已建立，須選適用條件

法源：[量體評定原則第4至6點](https://web.law.ntpc.gov.tw/Scripts/FLAWDAT0202.aspx?fcode=C0150118)，111年10月26日版。第5點適用依都市更新條例劃定之更新地區；基地位於更新單元的資訊仍須與公告更新地區範圍核對。

核心第3926行及第4031至4032行已有：

`倍率＝1＋更新地區0.3＋代金比例加計；評點量＝（基準量＋內部條件）×倍率＋外部改善採計量。`

代金達60%、80%、100%，分別加0.1、0.2、0.3；更新地區與全代金同時符合時採1.6。外部改善另計並限制於加計後內部條件三分之一，不把外部項目整組乘1.3。100%代金的送出位置組10分亦須採相應項目。

本次16組測試涵蓋雙北、更新地區開關、四種代金比例。新北基準12分、內部2分、外部目標5分、無代金加計：一般採14.6667%，更新地區採19.0667%。臺北倍率維持1；符合40%路徑仍受40%上限，並保留個案更低限制待修事項。

介面目前：在容移細項勾選「依法劃定更新地區：基準量及內部加0.3倍」；單選都市更新不自動勾選。快速目標25%直接採目標值，評點模式才由條件推算。這兩種輸入方式應補上差異說明，避免使用者以為25%會自動變成32.5%。
