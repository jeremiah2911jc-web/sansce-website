## 實作範圍

四模組輸入與方案在此瀏覽器自動暫存，重新開啟時選擇恢復或建立新評估。土地清冊及地籍、面積、分區、來源與查證仍由使用者自行確認輸入。恢復後重新計算／核對，不將舊試算結果及確認歷程恢復為目前成果。格式及規則版本可辨識，空白、未知、NaN 與零分開；暫存容量／權限錯誤及多分頁版本衝突明示，原暫存不悄悄覆寫。可刪除暫存，當下輸入仍保留；只切換工具不會重建已刪除的暫存，再次修改輸入才重存。

四模組提供摘要預覽及瀏覽器列印／另存 PDF。主要結果與條件、日期、規則及來源提交版本置於首張，詳細條件、假設、限制及來源另附頁。土地／透天沿用既有來源失效門檻；集合住宅修改後收起舊結果。重劃有缺件仍可輸出清楚標示的待核摘要，原確認與分回後土地草稿門檻不變。法定分配模式的係數、宗地／街廓及來源列入附頁，不新增金額計算。

結果圖表讀取現有核心欄位：集合住宅容積及樓板構成、透天計容分類及登記分項、土地用途檢核狀態、重劃各階段面積對照。不同口徑不相加；未知顯示待確認，正值小於0.01另作標示。未新增3D或方案比較引擎。

沒有修改計算模型、生成核心、規則公式、既有欄位、費用與財務範圍。沒有雲端案件、個案上傳或 App 同步。手機維持第一批既有介紹範圍。

## 預覽方式

在電腦進入第二批預覽，四個工具切換列保留原有功能。集合住宅可輸入假設基地後計算，結果下方有圖表及「預覽評估摘要」。使用者自己的地號、面積與規劃條件仍須核對。重新整理可驗收恢復流程；需要雲端備份及完整案件管理時仍由 App 承接。

本機暫存僅對同一瀏覽器及同一網站來源有效；不同本機連接埠的預覽互不共用暫存。正式發布需另經使用者明確授權，本輪沒有上架。
