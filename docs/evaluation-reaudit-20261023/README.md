## 本輪修正與使用者追加

- Safari原生列印時，modal頂層內容忽略強制分頁，部分明細接在摘要首張。列印前將同一文件暫轉一般文件流，結束／取消後恢復摘要視窗及捲動位置；摘要後另起明細，沒有更改計算或資料。
- 列印與另存PDF固定淡色三策浮水印；使用小篆的「三策」字形輪廓，公司全名使用易讀字體。輸出範本不提供關閉、移除、位置、尺寸或濃度設定；不接受案件檔覆寫浮水印。瀏覽器列印背景原為關閉，本次實際PDF仍可見浮水印。
- 浮水印由固定SVG圖形承載，不依賴使用者安裝篆體字型。字形取自 [開元小篆](https://github.com/frankslin/kaiyuan-small-seal-font)，OFL 1.1授權存於 `public/licenses/kaiyuan-small-seal-OFL.txt`。採用U+3D066（三）與U+3DD7B（策），參照其字形及Unicode現代字映射逐字目視核對；不是宣稱整套早期字型已全面驗證。
- 摘要版本統一呈現日期及實際版號，例如2026-10-17 · V1；土地V4、透天V1、重劃V6依原版本，不改成虛構版號。移除公開摘要內部模組名稱與來源提交碼；法規來源、填報依據及查證日期保留。內部規則指紋與案件檔相容性檢查不變。
- 上述限制是網站產品操作範圍，不宣稱可防止外部PDF編輯、截圖、裁切或開發者工具移除。JSON案件檔仍為原輸入資料格式，不是帶圖形浮水印的報告。
