# 蔣沈政見文章語意與句型再次盤點

日期：2026-10-27。狀態：本機修訂，尚未重新上架。

全文67段、兩張表格與對外摘要已覆讀。此次修正24組表述、26處文字，含側欄重複引用；各節原引註、18筆來源、表格、網址、主標與日期保留。本次為文字盤點，不另宣稱政策或法規最新狀態已重新查核。

## 主要問題與修正

- 導言將實績、住宅出資與分配混列，再用「算清楚」收束：改成蔣公布開工與交屋實績，沈交代住宅來源與出資，兩人各列地主分回、費用及延誤責任。
- 未交代「完成」的階段：分列招商、開工、完工、交屋，法定預算與預算案也分清年度及可用狀態。
- 「程序速度」「一定核准進度」「後面九成關卡」含糊：改成送件到核定、開工到交屋的時間，及計畫核定、其他許可與招商門檻。
- 「讓居民連同坪數決定」「把土地價格移開」「兩項成果」搭配不清：重寫行為、比較對象與明確受詞。
- 結尾重複保留意見與籠統責任：保留開頭一次資料限制，結尾交代實績、經費、補款、延期賠償及接手。
- 正式規範名稱中的「處理」保留；一般敘述不使用它代替具體動作。
