# 空白表單開挖上限與法規來源修正

2026-10-24，使用者確認本輪先修正「法規來源與開挖率0」，其他預設規劃條件維持。

## 問題及實作

- 共用地下室元件未檢查基本資料即解析開挖上限，空白面積所得的0通過有限數值檢查而出現在唯讀欄位；另將一般法條及網址當作唯讀來源欄位顯示。
- 網站呈現介面改為：基地面積及建蔽率須有效，且規則檢核沒有錯誤，才呈現上限；空白、部分缺漏、無效資料及清除後均保持空白。同時涵蓋新北、臺北及南港分支。
- 一般法規改為欄位外的「法規依據」連結。空白基本資料時不先出現；個案開挖限制、較嚴格都市計畫及資格來源欄仍維持人工填寫。
- 使用可重現的網站元件轉換，不直接修改生成模組或App來源。共用core.mjs與land.mjs經同步的路徑差異核對後，已保持與原提交完全相同；計算、資格、個案資料及其他預設值不變。

- 無預填法規來源欄位、無水平溢出、無頁面執行錯誤；另實際填寫個案來源欄，確認仍可使用。
