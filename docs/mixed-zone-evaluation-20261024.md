# 集合住宅單一分區與跨分區：法規及建置紀錄

2026-10-24；開發中，未發布、未安裝正式 App。此文件是實作規格及查核紀錄，不是個案建照可行性結論。

## 使用者最新要求

- 集合住宅分成單一分區與跨分區兩條操作路徑；單一分區須區別住宅、商業，依臺北／新北及個別都市計畫檢核。
- 臺北商業區臨路寬度、面寬及適用範圍的限制必須同時進入原有單一分區計算，不能只加在跨分區子模組。
- 同一套強度／用途／配置規則供兩條路徑及網站、App 共用。不能用「跨分區」隔離規則後讓原有商業區計算繼續套住宅假設。
- 個案只輸入原始文件已知值；不由助理先算平均容積率、假設住宅面積或店舖比再填。未知保留未知。
- 獨立模組不等於配置強制分區，不能一律禁止依法可跨區配置的空地與樓地板。
- 雙北法規查核與邊界測試未完成，不標示支援完整、不正式上架。

## 已核對的中央原則

1. 建技設計施工編第1條一宗土地、第29條空地／高度、第160條都市計畫法令書圖另有規定、第165條跨分區空地與樓地板配置須一起核對。第165條排除都市計畫法第32條其他使用區、特定專用區；公共設施及都市／非都市混合不可逕推適用。來源：https://www.nlma.gov.tw/ch/legislation/law%26regusw/6175
2. 第29條的空地分區計算不是分區留設義務，第165條的樓地板配置彈性也不是增加總容積。額度來源與配置所在地各有帳，不以某區差額負數直接判違法。
3. 79.7.6營署都字10351函支持住商合併建築，但使用依各分區。來源：https://www.nlma.gov.tw/ch/titlelist/interpcomp/6495
4. 65.10.4台內營694294函：用途依座落分區；仍要檢查有效的地方例外，不能寫成無例外的永久硬限制。來源：https://www.nlma.gov.tw/ch/titlelist/interpcomp/5748
5. 87.2.10台內營8771228函有容積管制／未管制混合的特定事實，不能當成所有跨區樓地板必須鎖回來源分區的依據。來源：https://www.nlma.gov.tw/ch/titlelist/interpcomp/12338
6. 第59條先依都計法令／計畫，未訂才適用中央表；幢別、用途分類、一次免設、面積排除、進位、公有身分分別判讀。來源：https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0070115&flno=59

## 臺北查核重點

現行官方頁列114.7.9修正：
https://laws.gov.taipei/Law/LawSearch/LawArticleContent/FL003962

- 第25條：商業區表定強度以外另有道路寬度限制；面寬5公尺及15倍面寬周長圈定最大適用範圍、次寬道路、未涵蓋範圍均須區分。不得看到商三就直接採560%。建蔽放寬另有前提，不自動採最大值。
- 案例8705允許跨住三商三以一宗基地最寬計畫道路核計，須併核現行第25條及個案計畫；不能僅看商業區本身臨哪條路，也不能反向把全部土地無條件套最寬道路。來源：https://www.dbaweb.tcg.gov.tw/taipeilaw/law_content.aspx?ID=11708
- 使用組與附條件標準須分別記錄；附條件標準第4條有住宅加級／非加級跨區的特殊條件，需核完整條件才可採。來源：https://laws.gov.taipei/Law/LawSearch/LawArticleContent/FL025529
- 第86-1條：住宅、零售及辦公汽機車標準不同，按同幢各類累加後進位，不套中央300／500免設。第86-2條裝卸位另算。
- 後側院、建築物高度比、鄰幢間隔、法定空地綠化、開挖及日照另核，合併配置不豁免。

## 2026-10-24 公設土地範圍與採計修正

公設土地不能概括說成「不得位於都市更新事業範圍」。都市更新條例第35條區分主要計畫變更及局部修正／細部計畫的程序；第36條列有區內公共設施計畫，第51條規定範圍內公共設施的權利變換處理，第66條另處理容積移轉。公設用地的更新範圍、可建築基地、容積與建蔽計算土地、法定空地分別判斷。

新北市都市更新單元劃定基準115年1月9日現行第六點末項規定，該點更新單元面積僅得計入可建築基地面積；不能以整體範圍總面積測門檻。第二點另有計畫規定從其規定，第四點對主要計畫變更設限制及施行細則第21條例外。歷史案件須再核適用版本，不能倒套新規。網站目前顯示此限制，尚非自動完成更新單元合法性判定。

預覽核心修正：公設身分填入採計面積，須另提供現行計畫明文允許或已發布實施變更的依據及有效日期，並保留逐項採計圖說。沒有依據的正面積阻擋，不再只是警示。廢巷、改道、取得或更新計畫核准均不代替都市計畫；不強迫本來合法允許的公設使用一律先變更。未知仍為未知，不自行補0；已依文件確認不採計者才列0。更新範圍紀錄不因此刪除，容積移轉另列接受基地。
