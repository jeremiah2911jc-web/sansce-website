# 看板說明必要性盤點（2026-10-21）

判斷原則：會改變數字解讀的限制保留，但集中一次；沒有當筆差異的重複說明刪除。常用畫面先呈現資料，詳細規則按需展開。統計和追蹤規則不變。

| 位置 | 決定 | 理由與結果 |
| --- | --- | --- |
| 每位訪客的來源長說明 | 刪除 | 來源欄位已明示依據與缺漏；來源總覽已有統一說明，無須每位重複 |
| 每位訪客的同一瀏覽器／換裝置說明 | 刪除 | 清單頂部已交代一次 |
| 正常操作明細前的整段通用說明 | 刪除 | 直接顯示時間與操作；不相關的工具、諮詢和舊版追蹤說明不塞進每位訪客 |
| 操作資料缺漏 | 保留一句 | 只有實際缺漏才顯示：未能取得、當時未記錄點擊與捲動、部分瀏覽缺少操作 |
| 時間、捲動、聯絡點擊、工具重算限制 | 集中一次，預設收合 | 放在訪客清單頂部「時間與操作怎麼看？」；仍保留顯示時間不等於閱讀、點擊不等於完成聯絡等邊界 |
| 案件報告說明 | 常駐兩句，其餘收合 | 開啟不代表讀完、跨日與重新整理如何計數影響當下判讀；完整細則保留按需查看 |
| 網路位置與縣市 | 常駐一句，其餘收合 | 留下網路估算不是實際所在地、國外只按國家；歷史日期與詳細分類規則收合 |
| 各地文章人次說明 | 常駐一句，其餘收合 | 人次不能直接相加是必要限制；不重複前面的地區、閱讀和聯絡說明 |
| AI 說明 | 常駐一句，其餘收合 | 留下提問與瀏覽分開計算、包含回覆失敗；輸入檢查和狀態細則收合 |
| AI 沒有無法辨認的提問訪客 | 不顯示重複說明 | 有實際缺漏才顯示具體次數，沒有缺漏時不再加通用段落 |
| 全站統計範圍與計數規則 | 頁尾集中，預設收合 | 保留重新整理、返回、跨午夜和排除測試等規則，避免每次瀏覽都經過長文 |

沒有刪除來源、顯示時間或操作的缺漏標示；零次與沒有紀錄仍分開。事件名稱中的「不代表完成計算／已送達」等短限制仍保留。
