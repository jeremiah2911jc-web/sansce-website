# 服務章節導覽遮擋修正

原發布版本：70dd5a1。使用者於上架後提供Safari合建服務頁截圖，顯示章節導覽縮成文字寬度，覆蓋「合建提案逐項檢視」標題。本次為原上架範圍內的排版缺陷補修，沒有新增照片、改寫服務文案或調整首頁順序。

## 原因與修正

- 閱讀區沿用舊版align-items:start，新的黏附導覽沒有指定伸展寬度，因而縮成內容寬度。指定完整閱讀欄寬與伸展對齊，防止文字從導覽旁邊露出，形成局部遮擋。
- 章節、段落與表格列的錨點，改用實測頁首及導覽高度，再扣除頁面既有scroll-padding，避免重複估算或固定像素失準。
- 頁首與導覽觀察border-box，將padding及縮高變化納入；目前主題依可見閱讀位置更新，兼顧直接帶錨點開啟後的版面位移。
- 規則補上導覽全欄、自然捲動、點選與直接帶錨點開啟的驗收要求。先前只確認連結可用及水平溢出，沒有攔住局部遮擋，已補足該檢查。

## 驗證

公開建置通過。Chromium與WebKit，1440、1280、360、390、430px，四個服務詳頁共40組組合；170次章節點選與40次直接帶錨點開啟，確認導覽全欄、頁首避讓、標題可見、目前主題及自然捲動遮罩。原生Safari桌機及390×844回應模式另留截圖。此為響應式驗證，不宣稱實體iPhone測試。

共用頁首量測有變動，因此另重查20篇文章、80個捲動位置的進度條，均維持頁首下緣；首頁照片／文字動態與助理收合正常。既定暫緩素材未變。

證據位於同輪工作資料夾service-nav-fix-20261026：results.json、progress-motion.json及screens。正式站發布與複查結果另留於同資料夾。
