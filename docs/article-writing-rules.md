# 三策文章寫作與上架前盤查規則

依使用者2026年10月24日至25日明定要求，適用三策觀點全部既有文章、新文及改稿。同步規則頁：https://chatgpt.com/space/page_8387183e7c688191a92a547c06566585。

## 直接論述

先寫具體情境或明確主張，再說明事實、制度、條件、因果及對地主的影響。每段完成一個論點；不以空泛口號、浮誇比喻、抽象金句或重複立場標籤代替分析。不虛構案例、實務經驗或統計。

文章主標、小標、摘要、導言、正文、引言、圖說、圖片文字、延伸閱讀及SEO資料均禁用設問、反問、自問自答、假想讀者對話，以及中文或英文問號。禁用「怎麼」「為什麼」與句末「嗎」「呢」等對話式疑問語氣。改稿須把問題寫成有依據的判斷、條件與結果，不只刪問號或換成仍吊胃口的陳述。

## 禁用句型與詞彙

- 禁用以「自動」描述權益、資格、分配、完工、責任及推論結果，包括「自動變成」「自動取得」「自動增加」「自動完成」「自動涵蓋」「自動等於」及否定式。直接列明成立條件、程序、計算或責任。法令規定免申請時，具體寫明符合的條件與免申請事項。
- 禁用「不是……而是……」「不在……而在……」「不能只……還要……」等對照套句。
- 禁用「真正」「從來」「口徑」「對帳」；不用「往往」「其實」「很多時候」代替事實依據。
- 禁用「值得注意的是」「更重要的是」「這也提醒我們」「讓我們先思考」「值得警醒」「有一個更前面的問題」「背後還有一個問題」及同型空泛鋪陳。不用「有時候」開頭。
- 禁用「我們很容易問」「一個很深的」「整理情緒」「需要一直記得」「……長出來」等AI套語。刪除不增加意義的強調詞，依句子內容重寫，不機械套用替換詞。

## 具體動詞與評論責任（2026-10-27使用者逐段修正）

- 不用「處理」代替估價、補繳、領取、補償、終止、變更、清償、承接、補強等具體行為；正式法規及規範名稱保留原文，不機械刪除單字。
- 寫「檢驗、確認、比較、說明」時，接著列明資料、比較項目、計算方式、支付對象或負責人；不以抽象名詞堆疊代替論點。
- 刪除「有分析價值的批評」「較精準的評價」「值得承認的進度」及替文章自評的句子。直接交代事實、結果與批判依據。
- 「交換對價」「共同負擔」「差額價金」等專業名詞可保留，但須寫清楚涉及哪些財產、由誰支付、如何計算。住宅成果依實際階段寫作完工、交屋或住戶拿到新屋，不泛稱交付成果。
- 改寫範例中的問句，仍依本檔既有直接論述規則寫成陳述；政策事實與作者主張分開，不藉文字潤飾新增未查核的事實。

## 事實與版面

法律、政策、數字及個案事實應查核一手資料。保留已查證事實、估算假設與分析之間的區分，必要限制緊接相關主張。引用不得改變原資料的意思；來源名稱可簡潔標示其主題與日期。

不用粗體及章節序號。每個思想放在同一段，進入下一層論述才空一行；正文靠左，依欄寬自然換行。標題依完整詞組檢查換行，禁止截字或縮小掩蓋問題。

## 每次上架前的內容盤查

1. 執行 `npm run verify:article-copy`，掃描全部文章資料及圖片文字。出現禁用語即阻擋建置。
2. 逐段人工覆讀主詞、行為、依據、條件及影響，檢查問句改寫後的銜接、假想對話、空泛前導及擬人化鋪陳。掃描通過不代表語氣合格。
3. 核對改稿前後的事實、數字、引用、原發布日期及網址；修改日期如實更新。標題改動同步處理列表、首頁、搜尋、分享、相關文章與SEO資料。
4. 完成建置、來源核對及桌機／手機／Safari版面驗收，保存各篇盤查與修正紀錄，再依使用者授權上架。
