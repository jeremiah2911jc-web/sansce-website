## 預覽驗收

五項工具均查看表單及收合區，集合住宅含四分頁、雙北及都更／危老切換；新增透天及重劃方案也已查看。51個填寫說明開關逐一操作，原生Safari確認鍵盤開關、填寫、計算與摘要。

空白新案填入1600㎡、建蔽50%、容積300%、都更50%、容移25%，其餘採規劃預設，每戶25坪。結果為允建容積8400㎡、房屋可售3762.69坪、135戶、59汽車位。Safari摘要相同，列明預設值與資格待查事項。

桌機欄位子項交疊及水平溢出檢查通過；360、390、430寬度維持電腦操作介紹頁。576項公開評估測試、表現層保全及公開建置已通過。範圍保全確認原數量函式除已記錄的規劃檢核與TOD擴充外保持一致。
