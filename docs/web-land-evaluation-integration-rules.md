# 網站與案件版：土地開發評估接入規則

版本：web-land-evaluation.integration.v2.3
確立日期：2026-10-21，依使用者最新明確指示修正。v1將成本與財務列入網站的規劃由本版取代。本規則不代表功能已實作或已上架。

## 1. 網站與 App 的固定界線

網站只提供前期開發評估：土地身分與用途、中央與地方及個案條件、用途檢核、變更途徑與必要文件、單棟與聯排配置及坪效、現況與變更後比較、本次評估結果及來源。

成本之後全部留在 App：逐項費用與規費金額試算、申請與工程期程估算、售價與地主分回、融資、收付款、受限款、現金流、利潤、投資報酬與完整財務報告。不得以分期交付、W階段、App已完成或共用核心為由擴張網站範圍。法定申請程序、前置同意、文件、限制及公共設施義務仍屬前期途徑資訊；不得將刪除成本工具解讀為刪除這些法規條件。

網站保持電腦操作；依2026-10-23第二批授權，在瀏覽器本機保存四模組的輸入與方案，供下次開啟恢復輸入。恢復後重新計算／核對，不沿用前次結果或確認紀錄。不建立雲端案件、不自動同步App、不讀取本機案件、契約或附件。不得把真實案件包進公開測試或網站產物。

## 2. 共用規則與計算核心

中央規則適用全臺；地方自治細則、公告、特殊範圍及個案核定條件另外疊加，不能以縣市推定都市或非都市，也不能把工業區一律當都市計畫內。都市計畫個別土管、農舍／廠房專用配置等未編碼範圍維持專案覆核。

網站直接使用案件版的土地規則、途徑及配置純計算來源，透過可重現同步產生瀏覽器模組；不得手抄第二套公式或刪改法定限制換取可計算結果。同步清單記錄來源提交、各檔案雜湊、規則版號與依賴。不得帶入Tauri、本機儲存、案件資料、成本或財務模組。

同條件驗證兩端用途判斷、候選途徑、面積、建蔽容積、退縮、高度、重疊、登記分項、停車及坪效一致。未知不填零，缺件不等於核准，法規覆核日與預定申請日分開，超出覆核期間降為待查線索。

## 3. 資料與操作

逐筆土地於操作期間保留，並依本機暫存規則保存：縣市、鄉鎮、地段地號、面積、管制體系、分區、編定、都市計畫、查證狀態、文件日期、既有核定用途與限制。混合管制可同案，配置依土地分組，不任意移用不同分組容積。

用途與途徑包括目標用途、必要申請人資格、全案及依法累計規模、條件、例外、程序、文件與地方差異。選定用途或主張例外不等於取得核准，文件免附不免其他同意。

配置包含現況／變更後基準、所選土地及候選途徑、中央／地方／個案採用依據、矩形範圍與退縮、逐棟逐層、道路排水綠地與停車、計容免計及登記分項。全案土地坪效與建築基地坪效使用同一總樓板，房屋登記與停車另列。矩形配置不冒充實際地籍或建築圖說。

本次可保留多個配置與確認結果供比較；替代方案不相加。上游修改後，原結果標示來源已變更；新結果須重新計算及確認，不能混用新土地與舊面積。新來源另建比較版本，原輸入與結果保留於本次操作。

原有集合住宅規劃與停車功能保留，與透天配置分流；不以集合住宅銷售係數換算透天。

## 4. 接入階段與狀態

| 階段 | 網站交付 | 驗收 |
| --- | --- | --- |
| W0 | 兩端規則、資料契約與能力界線 | 網站停在配置坪效；成本與財務僅App |
| W1 | 土地身分、用途、中央共用與地方覆蓋 | 全臺共用、正式／假設／未知分列，來源可查 |
| W2 | 候選變更途徑、適用條件、例外、程序、必要文件與地方差異 | 不套用錯誤制度，不顯示費額與期程試算 |
| W3 | 單棟／聯排配置、坪效與本次比較 | 同條件App對算、來源變更、面積及分組守恆 |
| W4 | 本次前期成果與預覽驗收 | 原生Safari桌機、既有電腦操作限制與舊功能回歸 |

原v1的網站成本／財務W4及財務延伸規劃作廢。重劃／徵收另依專屬規格分期；網站仍受本文件上限約束，其收購成本、資金、效益及價格反推留在App。此次不擅自新增未實作的重劃功能。

## 5. 介面、文案與公開產物

沿用網站品牌與設計規則；以土地編目、條件核對、程序、配置圖與面積表呈現各種資訊，不用重複彩色側線卡片、大片空白側欄或巨型表單卡片。並排輸入與選單等高，長選項完整可讀。

標題與文案使用直接、具體的專業陳述；不使用AI對話、問句、功能介紹式引導。保留必要條文、資格、例外、公式、前提及來源，不為短文案刪除專業內容。空白頁不預填模擬數值冒充實際操作。

僅記錄不含個案輸入的必要功能事件，不傳送地號、姓名、價格、查證文書或試算內容。公開產物須檢查沒有App資料、私有資料與桌面依賴；前期資料與畫面不提供成本及財務操作入口。

## 6. 必要驗收與交付

同條件覆核全臺22縣市、都市／非都市／特殊管制、甲乙丙丁建與農牧、用途與農舍資格、50戶或1公頃含累計門檻、變更乙建及法定例外、現況／變更後、單棟與聯排、混合分組、缺面積、停車、超容積／建蔽、退縮重疊及來源變更。檢核適用範圍照實列示，不以22縣市目錄冒稱全國所有地方細則已編碼。

分別記錄核心對算、App已驗證來源、網站接入、實際預覽及正式發布狀態。預覽使用模擬資料時清楚標示；完成後恢復空白入口，App回到實際案件。原生Safari桌機實際操作與完整頁面須驗證。依使用者2026-10-21補充指示，本開發系統不提供手機操作，不進行手機版面驗收，保留既有電腦操作限制。只讀文字或建置通過不能代替畫面驗收。

本次僅製作可操作預覽，不推送會自動部署的正式分支、不發布正式站。正式上架須由使用者明確同意。

兩端同名文件保持一致；AGENTS.md、網站設計規則及專屬規格相關敘述須符合此界線。後續如需擴張網站範圍，須使用者另行明確指示。

## 2026-10-21 盤點修正：欄位、證據與確認門檻

- 公開網站的送出地取得成本、代金估價、規費、已繳款及捐贈基金金額試算均留在App；公告現值作法定容積數量換算依據時可保留，與成本欄位分開。共用元件的財務欄位預設供App使用，網站明確關閉；驗收須展開送出地、代金、混合及獎勵細項。
- 重劃／徵收逐筆填寫納入面積、持分分子／分母、依據及日期。納入面積不得超過登記面積；各筆權利面積計算後加總。舊共同持分不得自動套用於多筆土地，須逐筆覆核。
- 文件、範圍、持分及事件日期不得晚於評估基準日或本版查核日；未來預定取得日期屬計畫條件，不冒充既成文件事件。超過覆核期間不得確認。
- 待核紀錄與確認結果分開。必要文件未齊、權利有障礙、面積未知或日期無效時，不可確認或建立分回土地草稿。待核紀錄可在本次頁面保留，須明示狀態；確認結果變動即失效。
- 建立分回土地草稿須有當次已確認且未變更的結果、文件分配面積、分配／交地階段及必要承接文件；草稿仍維持未知土地制度及假設狀態，後續用途與可建條件另核。
- 文案可縮短，但「規劃假設、文件記載、待查證、圖說待核、核定文件對照」等必要身分不得刪除。不得用全域字串刪除抹去資格、排位、登記或未支援範圍。
- 新增驗收包括不同逐筆持分與部分納入、未來／基準日後文件、必備文件誤選不適用、待核留存、確認後改值失效及App財務欄位保留。維持本機預覽，不部署。
