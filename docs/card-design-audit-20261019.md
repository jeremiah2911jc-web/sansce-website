# 全站卡片設計盤點

盤點日期：2026-10-19。依使用者提供的論壇海報截圖，辨識與禁止制式裝飾卡片風格。規則已寫入 `website-design-rules.md`，並由根目錄 `AGENTS.md` 強制引用。

## 本次範圍與證據界線

本次完成全站路由入口、主要 JSX 元件及共用／專頁 CSS 的原始碼盤點，並以原生 Safari 開啟正式 `/consulting`，目視確認服務區的四張白色圓角卡、淡彩圖示底座及重複版型。其餘項目為原始碼發現，尚未逐頁完成正式畫面與手機驗收；不可把本文件當成全站視覺驗收通過或已完成改版。

使用者後續要求直接重新設計並先交預覽。本次已修改下列主要元件的版面與樣式，保留既有資料與計算邏輯；首頁服務區亦已改為主次分明的照片卡片組。僅啟動本機預覽，未部署正式網站。

## 後續改善與驗收

1. 優先處理已確認的服務卡、關於頁理念卡與專案結果卡，逐一記錄修改及驗收狀態。
2. 不以全域清除圓角／陰影的方式處理；先確定內容結構，再修改相應元件與有效樣式，核對 CSS 載入順序，避免新增覆寫層掩蓋舊問題。
3. 桌機及 360／390／430px 手機完整頁面目視檢查，含選取、展開、輪播及計算前後狀態；確認連結、可操作性與資訊色彩語意。
4. 真正修改頁面時執行相關建置、功能及路由檢查；部署須取得使用者上線授權，並在正式網址另行驗收。本次文件更新不代表部署或改善完成。
