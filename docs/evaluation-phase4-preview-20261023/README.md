## 實際完成

- 官方查詢輔助：在逐筆土地、集合住宅及重劃資料區提供可展開的查詢入口。地籍位置、電子謄本、全國分區及地方書圖分開；臺北／新北提供專屬入口，其餘導向官方地方查詢目錄。來源核對與API可行性見 [官方來源紀錄](official-source-review.md)。
- 查詢所在地只改可見連結；固定網址不附本案地號、清冊或座標。地號、面積、分區、查證日期及依據仍由使用者自行核對填寫，不自動帶入或改成已查證。
- 頁頂案件檔下載與匯入：四模組輸入、人工來源、用途途徑、透天方案、集合住宅三案，以及重劃三制度兩主線輸入可帶走。檔案保留建立日、格式與規則指紋、未知及空白，不保存計算成果或確認歷程。
- 匯入先驗證、顯示筆數／方案與規則差異，提供目前案件備份。確認後替換；取消或格式／容量／儲存衝突失敗時保留原輸入。一次整批載入並重建畫面，不把新輸入與舊結果混用；依目前規則重新計算及確認。外部檔案不得替換應用程式自有的法規模板。
- 土地判讀缺件可選中對應地號、展開來源區並聚焦欄位；重劃文件缺件自動展開對應文件，缺原土地面積可切回正確土地。沒有明確映射的項目保留文字，不亂指欄位。摘要維持純文字，不加操作按鈕。

## 驗收

- 948項既有核心對算、第二批36項、第三批21項及本批45項，共1,050項通過。四模組核心模型及生成檔未變；規則來源雜湊仍一致。
- 本批涵蓋：完整案件往返、三案目前編輯值、未知／空白、方案關聯、不帶回成果、六種重劃組合、錯誤與未來格式、重複識別、巢狀格式、危險鍵、大小限制、官方固定連結及欄位目標。
- IAB實際透過檔案選擇器載入合成案件（2筆土地、1個用途途徑、1個透天、3個集合住宅及6個權利方案），下載檔再匯入；檔案解析與輸入筆數一致。不同規則版本及相同版本提示均檢查。
- 實際取消匯入後，剛修改的名稱保留；錯誤檔案顯示可讀錯誤，原三方案仍保留；確認載入後名稱回到檔案值、三案皆待計算、舊結果容器為0。有效規劃條件重新計算後可正常比較，原確認歷程沒有恢復。
- 第二筆土地缺面積可切到第二筆並聚焦面積欄；來源缺件自動展開來源段。重劃計畫欄、公告文件、徵收收購標的及跨模組原土地面積皆實際操作。透天尺寸、座標、方案、樓層與檢核保留，不恢復粗略配置圖。
- 桌機800／1024／1280寬無水平溢出；手機360／390／430維持首段介紹，工具與案件檔操作不顯示。
- Safari另開新分頁載入5191，進入土地模組並展開官方入口；可見地籍、謄本、分區與地方目錄。原生下載觸發Safari網站下載權限提示，本輪取消該提示、保留既有瀏覽器設定；實際檔案下載／匯入往返已於IAB驗證，不宣稱Safari完整匯入流程已驗證。
- 公開預覽建置、29頁SEO、公開路由及150資產檢查通過；既有大包體提示仍在，不宣稱效能已改善。
- 預覽交付前以空白案件清除本批合成測試資料，回到總覽；使用者舊5189與Safari其他分頁資料沒有替換。
